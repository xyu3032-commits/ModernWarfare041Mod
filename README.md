# 现代战争 ModernWarfare041Mod

《现代战争》是 DroneFlames **0.41 版**的现代战争题材模组（中国单位包）：把原版兵种槽位覆写成中国装备——开局选编制、兵营招募，开出来的就是中国单位。

- **陆军 8**：99A 主战坦克、合成步兵班、04A 步兵战车、迫击炮组、红箭反坦克组、合成突击队、PHL-191 箱式火箭炮、05 式自行榴弹炮
- **空军 6**：歼-20、轰-6K、空中炮艇、直-10、直-20、运-20
- **无人机 2**：翼龙攻击无人机、飞虻自爆无人机
- **导弹 5（真弹体）**：红旗-9B、红旗-17、东风-41、东风-17、长剑-10——飞出去的是导弹本体，不是发射车
- **海军 3 档贴图**：056 型护卫舰、052D 型驱逐舰、055 型驱逐舰（仅换贴图）
- 全部单位 16 向帧条按原版帧序约定制作（第 0 帧朝东、顺时针递增），前进方向与贴图对齐

## 安装（0.41.15 Workshop 导入）

1. 先确认游戏是官方 **0.41.15**（本 mod 的格式与接口按 0.41 制作，0.33 装不了、也不要往 0.33 里装）。
2. 在游戏的创意工坊（Workshop）/ 模组编辑器里选择**本地导入**，选中下载的 `.dfmod` 文件。
3. 导入后在编辑器里能看到 21 个中国武器条目（带中文名），可逐个点测试看贴图。
4. **正式对局**：把本 mod 放进对局的模组合集并启用，开局选编制——兵营按编制招募出的原版兵种会被覆写成中国单位的贴图与数值。

## 注意事项

- **仅适配 0.41**：不要装进 0.33 版游戏；本 mod 没有进 0.33 的游戏内商店，只能从本仓或官网（droneflames-mods.vercel.app 的 0.41 分类）下载后手动导入。
- **中英同 id 覆盖安装**：后装的覆盖先装的；两版存档键相同，切换语言请注意存档兼容性自担。
- **单位名字仍是原版名**：覆写机制改不了原版单位的显示名——对局里招募出的单位贴图和数值是中国装备，但名字仍显示原版名；编辑器的武器条目里能看到中文名，这是 0.41 覆写机制的已知限制。
- 海军只有 3 档换了贴图，舰船数值与原版一致；航母本版未做。
- 本仓库是该模组（0.41 线）的专属发布仓，与 0.33 线的《现代战争》（cn_us_military）是两个不同的 mod，不要混装。
